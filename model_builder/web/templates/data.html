How to use this page
  1. Upload your data file (CSV, JSON, Parquet, Excel, PDF, DOCX) using the form below. Files land in data/raw/.
  2. Edit pipeline.yaml to point the connectors.file or connectors.document node at your file.
  3. Run aimodelground run in a terminal. After the profile step completes, the Data Profile section here will show your column types and null counts.
  4. If something looks wrong (wrong types, unexpected nulls), fix the source data and re-run from the ingest node: aimodelground retry ingest.
